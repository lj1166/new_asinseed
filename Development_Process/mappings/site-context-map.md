# 全站业务功能—字段—页面角色—素材权利地图

> 这是新站产品规划的事实底座，不是旧页面导入清单。页面组来自 `page-map.md` 的批次 0 轻扫描；精确字段、URL、Controller 和素材权利只在对应 P1 后升级为事实。旧 DOM、布局、文案、图片和视频均不作为新页面默认输入。

## 全站使用规则

| 输入类型 | 可作为新站什么依据 | 权利/事实状态 | 新站默认处置 |
|---|---|---|---|
| 旧 JSP 路由、表单、字段名与用户动作 | 业务任务、DTO/Mock 边界、URL 对应的证据 | 仅在 P1 有路径:行号时成立 | 可进入 P2 契约；不得复制 DOM。 |
| 旧可见文案、标题、营销语 | 仅可帮助理解旧意图 | 不等于内容版权、产品事实或当前表达 | 新站原创重写；没有事实支撑的主张删除。 |
| 旧图片、视频、背景、Logo、第三方商品图 | 可能的素材线索 | `UNRESOLVED`，没有授权/时效证据 | 默认不迁移；优先代码原生图形或经授权的新素材。 |
| 旧账号、订单、支付、会员、查询历史 | 业务边界证据 | 涉及真实用户/权益/支付 | `exclude`，获得单独批准后再做真实接入。 |
| 新 Sanity 文档/上传素材 | 运营内容和已授权媒体 | 每项必须有消费者和来源/授权信息 | 仅与页面同批落地；不得建未消费配置。 |

## 页面组地图

| 业务功能域 | 已知字段/用户任务（精确程度） | 新站主页面角色 | 素材权利与内容策略 | 当前处置 / 下一步 |
|---|---|---|---|---|
| 品牌首页 | 品牌价值、工具入口、导航（组合层） | 品牌入口 + 工具引流 | 旧首页全部视觉/文案不迁移；品牌色 `#FF9200` 是已确认 token | 重构：首页直接嵌入真实工具入口，长尾内容迁往资源页。 |
| ASIN 反查 / 关键词研究 | `market`、`q`、ASIN/关键词分流、`supplement`、`exactMatch`、关键词与指标字段（P1 已确认） | 任务工具 | 产品图/背景/视频/旧文案均 `UNRESOLVED`；结果仅能来自明确的 Mock/未来真实 adapter | 合并为一个工具流，详见 `migration/inventory/cn-search-tool/inventory.md`。 |
| 热门 ASIN 程序化页 | 市场/类目/反查入口（轻扫描） | 内容引流（候选） | 模板、数据覆盖和素材权利均未验证 | `UNRESOLVED`；不可批量收录。 |
| 定价 / 价格 FAQ | 方案、异议、CTA（轻扫描） | 转化落地 | 价格和权益须有当前事实来源，不复制旧价格/支付措辞 | 批次 2 重构；支付不迁移。 |
| 浏览器插件 | 安装/升级说明（轻扫描） | 产品/功能 | 截图、下载、兼容性须重新确认 | 批次 2 重构。 |
| 产品视频 | 演示入口（轻扫描） | 信任/产品教育 | 旧视频和封面权利未确认 | 并入产品/资源内容，仅用可授权素材。 |
| 使用指南 / 流量词帮助 | 教程意图（轻扫描） | 内容引流 | 旧文章文字、插图质量与版权未确认 | 并入知识库/资源中心，原创内容优先。 |
| 帮助 / 联系 / 通用 FAQ | 支持、问题、联系意图（轻扫描） | 信任/支持 | 联系信息、答案与 FAQ 事实须人工确认 | 批次 3；只有真实问答输出 FAQPage。 |
| 博客 / 文章 / 帮助文章 | 列表、详情、内容类型（轻扫描） | 内容引流 | 素材与引用需内容工作流记录 | 批次 3；SEO/GEO 长尾主阵地，人工发布先行。 |
| 条款 / 隐私 | 合规文本（轻扫描） | 信任/合规 | 旧法律文案不可默认复用 | 批次 4，需人工确认文本。 |
| 账号、登录、用户中心、消息 | 登录、设置、权益、历史（轻扫描） | 账户/交易 | 用户数据、账号状态不可模拟为生产能力 | `exclude`。 |
| 支付、订阅、优惠券 | 订单、订阅、优惠权益（轻扫描） | 账户/交易 | 支付/权益事实与流程不可复制 | `exclude`。 |
| 后台管理 | 用户、内容、订单等后台动作（目录级） | 后台 | 旧 admin 不等于运营 CMS | `exclude`；运营内容使用新 Sanity Studio。 |

## 页面设计与收录分工

| 页面角色 | 主要任务 | SEO/GEO 作用 | 不应承担 |
|---|---|---|---|
| 首页 | 让目标用户理解品牌与核心工具，并立刻开始一次任务 | 品牌实体、核心主题、工具入口 | 长篇教育、重复 FAQ、伪 dashboard。 |
| 工具页 | 完成输入、反馈与结果解释 | 承接商业/工具意图；查询状态 `noindex` | 复制旧结果布局、伪造实时/会员数据。 |
| 产品/转化页 | 展示被核实的能力、场景与下一步 | 承接产品/商业意图与转化 | 长尾内容堆砌、未证实数据。 |
| 资源/博客页 | 解决细分问题、表达方法与来源 | 长尾收录和可引用内容的主要载体 | 充当功能页面的装饰性重复文案。 |
| 支持/合规页 | 处理真实异议、帮助和合规信息 | 信任信号 | 未经核实的承诺。 |

## 使用门槛

1. 新页面开始前，先从本地图选择一个页面角色与用户任务，再取其对应 P1 的字段事实；不能从旧 JSP 的视觉开始。
2. 任何素材进入 Sanity 或代码前，必须记录来源、使用权和消费页面；未知即不使用。
3. 任何动态查询在真实 adapter 未获批前必须显示为 Mock/验证数据，且查询 URL 不进入 sitemap/index。
4. 全站上下文的作用是避免功能遗漏与信息架构漂移，不是扩大旧内容迁移范围。
