# AsinSeed 视觉重构总体规划

> **核心目标**：建立现代化动态感 SaaS 工具网站，实现信任建立 + 会员转化 + 导流卖家精灵  
> **次要目标**：SEO/GEO 优化（后续阶段）  
> **设计哲学**：专业工具感 > 营销海报感

---

## 一、旧站诊断（基于 JSP 代码分析）

### 当前视觉问题

#### 🔴 严重问题
1. **视觉语言过时**（2018年 Bootstrap 模板风格）
   - 大量渐变背景 `.u-gradient-overlay-half-blue-grey-v1`
   - 过度使用阴影和圆角
   - 色彩系统混乱（橙色 #FF9200 + 蓝灰渐变 + 各种装饰色）

2. **信任感不足**
   - 首页客户证言用轮播图（用户看不完就滑走）
   - 合作伙伴 logo 墙密集度过高（缺少层次）
   - 产品截图陈旧，缺少真实数据展示

3. **转化路径不清晰**
   - 首页输入框与价值主张分离
   - CTA 按钮"获取流量词"不够有吸引力
   - 没有"免费试用 → 看到价值 → 付费"的渐进式体验

4. **导流策略缺失**
   - 搜索结果页底部小字提示卖家精灵（太弱）
   - 没有在关键决策点引导用户升级到主产品

#### ⚠️ 次要问题
- 移动端体验需要优化（输入框过小、表格横向滚动）
- 动效单一（只有淡入淡出，缺少状态反馈）
- 排版密度过高（信息过载）

### 3.3 首页关键设计决策

#### ① Hero 区：工具即刻可用

**旧版问题**：
```html
<!-- 旧版：大渐变背景 + 居中输入框，感觉像搜索引擎而非专业工具 -->
<div class="u-bg-img-hero u-bg-keyframes">
  <div class="u-gradient-overlay-half-blue-grey-v1">
```

**新版方案**：
```typescript
// 视觉语言
背景：纯白或极浅灰（#FAFAFA）
标题：直接说明功能，而非口号
  ❌ "超准确的亚马逊关键词反查工具"（太长，太营销）
  ✅ "一键反查竞品核心流量词"（动词开头，结果导向）

输入框：
  - 更大（16px 字号 → 18px）
  - 默认示例已填充（B07XYZ123）
  - 市场选择器更明显（国旗 + 站点名）
  - 查询按钮文案："免费查询"（而非"获取流量词"）

实时反馈：
  - 输入时显示建议（已有功能，保留）
  - 显示"今日已服务 X 次查询"（真实数据，建立信任）
```

#### ② 即时预览区：先展示价值，再要求注册

**策略**：
```

1. 看到真实的查询结果示例（前 3 行清晰）
```

## 六、设计系统规范

### 6.1 颜色系统

```typescript
// 品牌色：橙色（仅用于 CTA、焦点、强调）
const colors = {
  brand: {
    primary: '#FF9200',
    hover: '#E68300',
    light: '#FFF5E6',  // 用于背景
  },
  
  // 中性色：主要用于文本和界面
  neutral: {
    50: '#FAFAFA',   // 背景
    100: '#F5F5F5',  // 卡片背景
    200: '#E0E0E0',  // 边框
    600: '#757575',  // 次要文本
    900: '#1A1A1A',  // 主要文本
  },
  
  // 功能色
  success: '#10B981',  // 数据正增长
  warning: '#F59E0B',  // 需要注意
  error: '#EF4444',    // 错误状态
}
```

**使用原则**：
- 橙色占比 < 10%（只用于关键行动）
- 90% 使用中性色（黑白灰）
- 避免大面积彩色背景

### 风险 2：用户不适应新界面
**应对**：
- 保留旧版访问入口（/cn/legacy）
- 逐步灰度发布（10% → 50% → 100%）
- 收集用户反馈快速迭代

### 风险 3：性能下降
**应对**：
- 图片懒加载
- 代码分割
- CDN 加速
- 关键 CSS 内联
