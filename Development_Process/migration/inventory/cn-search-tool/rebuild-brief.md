## 5. 设计方向

| 项目 | 方案 |
|---|---|
| 现代 SaaS 呈现原则 | 像一个可以立即操作的研究工具，而非一张介绍工具的海报；输入、状态、结果解释优先于装饰性卡片。 |
| 响应式重点 | 小屏上市场选择、输入、提交与状态按单列可触达；结果字段以任务优先级折叠，不横向挤压核心输入。 |
| 图片策略与展示比例 | 不迁移旧图片；用固定色块、细线 SVG、HTML `<output>` / `<progress>` 与状态标签建立产品感。 |
| 动效 / 交互 | 只对输入识别、提交、状态切换和结果出现提供即时反馈；使用 CSS transform/opacity 与 SVG 实线，不使用 `linear-gradient`、`radial-gradient`、blur/玻璃效果；`prefers-reduced-motion` 下停用非必要过渡。 |
| 可信度设计 | 明示当前为 Mock 验证数据、列出未接入范围；不展示虚构实时指标、客户背书或解锁状态。 |

## 6. SEO / GEO 与转化关系

| 项目 | 方案 |
|---|---|
| index / canonical / hreflang | 稳定无 `q` 的主工具入口由 P2 选定 canonical；带 `q` 的查询状态 `noindex` 且不进 sitemap；仅 `cn`，不输出 hreflang。 |
| 可直接引用的答案或证据段落 | 在页面初始 HTML 中简明解释“输入 ASIN 时返回关联关键词研究视图；输入关键词时返回趋势/需求字段视图”，并指明数据接入状态。 |
| 结构化数据（仅真实内容） | 工具入口使用 `WebPage`/`SoftwareApplication` 的适用性待 P2 判断；不为查询结果输出 FAQ、评分或数据声明。 |
| 内链：本页如何承接/导出意图 | 首页主入口 → `/cn/US`；完成任务后可在批准的 `sellersprite.ai` registry 路径继续研究。 |
| 与博客、资源、案例页的分工 | 本页完成任务；后续博客/资源页承担教程、长尾问题、方法与可引用内容。 |
