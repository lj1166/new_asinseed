## 5. 设计方向

| 项目 | 方案 |
|---|---|
| 现代 SaaS 呈现原则 | 首页是产品起始面，不是宣传长页：让可操作的搜索入口成为视觉中心，品牌和方法解释围绕它服务。 |
| 响应式重点 | 首屏完整出现价值、输入和按钮；移动端不把工具入口隐藏在二级 CTA 后。 |
| 图片策略与展示比例 | 采用代码原生的“研究轨迹”细线/状态点作为装饰，不迁移旧背景和插图。 |
| 动效 / 交互 | 输入识别、按钮反馈、轻量状态点和滚动进入的层级变化；禁用渐变、模糊玻璃与装饰性伪图表，支持 reduced motion。 |
| 可信度设计 | 在工具入口附近明确其当前结果数据状态，不展示未验证数字和客户标识。 |

## 6. SEO / GEO 与转化关系

| 项目 | 方案 |
|---|---|
| index / canonical / hreflang | `/cn` 自 canonical、index、sitemap；仅 `cn`，无 hreflang。 |
| 可直接引用的答案或证据段落 | SSR H1/副标题直接说明工具能帮助什么用户完成什么研究动作；方法说明只说 P1 已证实的输入/结果语义。 |
| 结构化数据（仅真实内容） | 保留现有 `Organization`/`WebSite` 实体关联；移除不再在可见页面出现的 FAQPage。 |
| 内链：本页如何承接/导出意图 | 首页主入口进入 `/cn/US`；后续资源页上线后承接教育型长尾意图。 |
| 与博客、资源、案例页的分工 | 首页负责起点与信任；工具页负责操作；博客/资源负责深度、长尾和可引用内容。 |
